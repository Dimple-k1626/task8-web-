# Simple Blog Layout Using Bootstrap 5

## 📌 Task 8: Create a Simple Blog Layout Using Bootstrap 5

This project demonstrates how to build a responsive blog page using Bootstrap 5 CDN.
The layout includes a navigation bar, blog cards, and a footer with social icons.

---

## 🎯 Objective
To create a responsive blog webpage using Bootstrap 5 featuring:
- Navbar
- Blog post cards
- Footer with social icons

---

## 🛠️ Tools Used
- Visual Studio Code
- Bootstrap 5 CDN
- Bootstrap Icons CDN
- Web Browser (Chrome / Edge / Firefox)

---

## 📁 Project Structure
simple-blog/
│
├── index.html
└── README.md

---

## 🚀 Features Implemented
- Responsive navigation bar
- Bootstrap grid system for layout
- Blog cards with image, title, description, and Read More button
- Fully responsive design for all screen sizes
- Footer with social media icons

## ▶️ How to Run the Project
1. Open Visual Studio Code
2. Create a new project folder
3. Add an index.html file
4. Paste the blog layout HTML code
5. Save the file
6. Open index.html in any browser
