# Simple Blog Layout Using Bootstrap 5

## 📌 Task 8: Create a Simple Blog Layout Using Bootstrap 5

This project demonstrates how to build a **responsive blog page** using **Bootstrap 5 CDN**.  
It includes a **navigation bar**, **blog cards**, and a **footer with social icons**, all styled using Bootstrap components and utility classes.

---

## 🎯 Objective
To create a responsive blog webpage using **Bootstrap 5** featuring:
- Navbar
- Blog post cards
- Footer with social icons

---

## 🛠️ Tools Used
- Visual Studio Code
- Bootstrap 5 CDN
- Bootstrap Icons CDN
- Web Browser (Chrome / Edge / Firefox)

---

## 🚀 Features Implemented
- ✅ Responsive navigation bar
- ✅ Bootstrap grid system for layout
- ✅ Blog cards with image, title, description, and button
- ✅ Fully responsive design for all screen sizes
- ✅ Footer with social media icons
- ✅ Clean and simple UI using Bootstrap utilities
